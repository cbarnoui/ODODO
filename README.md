# ODODO
PWA App for a task/time/reward system aimed at parents of young children

When starting the game, first select the number of player, then you can choose a custom timer/task(s)/reward, or one of the available presets. The presets are for school, playground and bedtime.

Once you click Go! the timer start and one needs to complete and select all the tasks in order to stop it and show the reward (if none was selected, the clapping hand are shown)

If you only select the timer option, you get a basic fullscreen timer. A sound is played when the time is up. Always useful!

You can deselect a task by holding it for 2 seconds
